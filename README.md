# کارینو

کارینو یک برنامهٔ آفلاین، فارسی و راست‌چین برای مدیریت کارهای روزمره است. ایدهٔ اصلی آن حفظ سادگی یک چک‌لیست سریع و برطرف‌کردن کمبودهای رایج برنامه‌های ساده—از جمله پاک‌شدن اطلاعات، نبود یادآور و نبود دسته‌بندی—است.

## امکانات نسخهٔ ۱.۰

- افزودن، ویرایش، تیک‌زدن و حذف کار با امکان بازگردانی حذف
- ذخیرهٔ دائمی اطلاعات با Room؛ بستن برنامه چیزی را پاک نمی‌کند
- دسته‌بندی‌های رنگی و ساخت دستهٔ دلخواه
- اولویت کم، عادی، مهم و فوری
- تاریخ کاملاً شمسی و ساعت ۲۴ ساعته
- یادآوری محلی با اعلان Android
- تکرار روزانه، هفتگی و ماهانه
- جستجو در عنوان و متن یادداشت
- فیلتر امروز، آینده، همه و انجام‌شده
- گزارش تعداد کارهای انجام‌شده در هفت روز گذشته
- تم روشن، تیره و هماهنگ با گوشی
- قلم فارسی وزیرمتن و رابط RTL
- تهیه و بازیابی فایل پشتیبان JSON از مسیر دلخواه کاربر
- عملکرد کاملاً آفلاین، بدون حساب کاربری و بدون مجوز اینترنت

> Android ممکن است در حالت ذخیرهٔ شدید باتری، اجرای اعلان‌های WorkManager را کمی به تأخیر بیندازد. خود کار و زمان یادآور از بین نمی‌رود.

## فناوری و ساختار

- Kotlin و Jetpack Compose / Material 3
- MVVM و جریان دادهٔ یک‌طرفه
- Hilt برای تزریق وابستگی
- Room برای داده‌های اصلی
- DataStore برای تنظیمات
- WorkManager برای یادآورها
- حداقل Android 8 (API 26)، هدف Android 15 (API 35)

## گرفتن APK با GitHub Actions (بدون کامپیوتر)

1. محتوای این پوشه را در یک مخزن GitHub قرار دهید.
2. در GitHub وارد زبانهٔ **Actions** شوید.
3. اکشن **Build Karino APK** را باز کنید و **Run workflow** را بزنید.
4. بعد از سبزشدن اجرا، فایل `Karino-APK-...` را از بخش **Artifacts** دانلود کنید.

برای ساخت محلی نیز JDK 17 و Android SDK 35 لازم است:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK دیباگ در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## حریم خصوصی

برنامه مجوز اینترنت ندارد. تمام داده‌ها در پایگاه دادهٔ داخلی گوشی نگه‌داری می‌شوند و فقط زمانی از برنامه خارج می‌شوند که خود کاربر با گزینهٔ «تهیه پشتیبان» یک فایل بسازد.
